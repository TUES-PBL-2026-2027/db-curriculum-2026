# Lesson 1 — Why Databases & the Relational Model

**Module 1 · Database foundations and basic SQL**

## Objectives

- Explain why databases/DBMSs exist and what they guarantee over plain files.
- Describe the relational model precisely (relations, tuples, attributes, domains).
- Connect to PostgreSQL with `psql`, create typed tables, and perform CRUD safely.

## Start here

1. Read **`THEORY.md`**.
2. Load the database: `psql -d storefront -f setup.sql` (see the repo [README](../README.md) for first-time setup).
3. Work through **`PRACTICE.md`** using *Predict → Run → Explain*.
4. **Verify as you go:** run each query and compare the real output with your prediction; when they differ, work out why (re-read `THEORY.md`). Worked solutions are kept by your teacher.
